Ganga-Stock — Sistema Web de Gestión de Inventario y Ventas
Desarrollo completo de una aplicación web en Django para la administración de inventario, ventas y usuarios con control de roles y permisos.

Principales funcionalidades:

Sistema de autenticación con redirección según rol (administrador, cajero, bodega, vendedor)
Gestión de productos con imágenes, precios y stock en tiempo real (CRUD)
Control automático de entradas y salidas de inventario
Módulo de ventas con carrito, confirmación en caja y generación de boletas
Reportes dinámicos de inventario, movimientos y ventas con exportación a Excel
Administración de empleados y gestión de roles temporales o permanentes
Panel administrativo con supervisión de operaciones

Tecnologías utilizadas:

Django & Python
HTML, CSS, Bootstrap, JavaScript
SQLite / SQL
openpyxl para generación de reportes

Habilidades demostradas:

Diseño de sistemas web completos (backend + frontend)
Lógica de negocio y control de procesos
Manejo de bases de datos relacionales
Implementación de roles y permisos
Automatización de reportes
Desarrollo orientado a usuario
